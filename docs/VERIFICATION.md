## 玩家可以战胜有限策略

同一份“麦香鸡 + 中薯 + 中杯可乐”，玩家使用“人气经典随心配（麦香鸡 + 中杯可乐）+ 中薯”，本次官方报价 **¥27.40**；入门对手提前选择“麦香鸡中套餐”，翻牌时重新报价 **¥28.00**，玩家胜出 ¥0.60。

两边均通过同袋与回执检查；对手摘要标识前后一致，未看完玩家再换方案。该样本 traces 为 `ea4e378a0024ba1452f1bc2e0ea41559` 和 `c6e539b4442cf2d10a8759cde43e5738`。浏览器又独立操作复现了相同金额。

这是一个可玩性和接口完整性的证明。¥0.60 不是面向所有用户的节省承诺；当前对手不是完整菜单优化器，不把它称为“打败最强 AI”。

## 发现并修正的问题

初次调研曾把饮料子项当成顶层商品，接口成功但漏计饮料，导致不完整单点价。该结论已撤回，上表全部使用修正映射重新查询。实现现已把“商品回执完整性”设为判胜前置条件，并添加漏项回归测试。

浏览器测试曾被 CSP 禁止字符串求值；改用 Playwright 原生元素断言，保留页面 `script-src 'self'`，没有用开放 `unsafe-eval` 来绕过测试。

## 午夜后的门店可用性

2026-10-16 00:00:57，`query-meals` 返回 `success:false`、`code:600057`、`message:门店可能已关闭或不在营业时间`。这是官方当前业务结果，不是 Token 失效的证据。`query-nearby-stores` 同时仍成功。

真实模式会给出门店时段提示并停止判胜；训练模式仍可用。新建 `demo-live.mjs` 在午夜运行验证了该错误路径，完整成功路径由同一 `LiveArena` 的 API 与浏览器在此前实测通过。不要将这次失败写成新的成功核价记录。
