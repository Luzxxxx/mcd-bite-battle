项目简介：基于麦当劳官方 MCP 的单人点餐策略对战应用。玩家与策略对手或自带 API 的 AI，在餐品、份数、规格及默认配料一致的条件下比较不同买法。真实门店模式查询菜单、拆解套餐，并以官方整单核价结果判定；模型对手在开局时封存方案，翻牌时校验。训练场支持自由出题、同题挑战和战绩卡导出，帮助玩家在互动中理解套餐组合与价格差异。
