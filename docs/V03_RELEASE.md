# v0.3：带上你的 AI 来接招

玩家选择 DeepSeek、通义千问 / 百炼、硅基流动或兼容接口，填写 Base URL、模型 ID 和自己的 API Key，邀请 AI 独立出招，再亲自组餐、锁定和翻牌。模型必须支持 OpenAI 兼容工具调用。网页训练场与本机版都支持；本机真实局也能使用页面填写的模型。

默认仅向预设模型域名发送请求，不跟随重定向。其他兼容域名由站点所有者通过 `MODEL_API_ALLOWED_HOSTS` 配置，逗号分隔。不是所有兼容模型都支持所需工具协议；模型失败会显示错误，不切换对手。百炼、硅基流动的模型 ID 应按用户自己的控制台填写。

密钥只在本页内存与当前后端调用中使用，刷新或点击「清除本页配置」后清除。不写入应用日志、数据库、浏览器持久存储、分享 URL、战绩卡或对局票据。请求会经过应用后端与用户指定的服务商，请在可信站点填写。AI 的已验证方案保存在 15 分钟有效的加密票据中，不需要保存玩家密钥；翻牌时重新计算双方价格并验证最初的 SHA-256 承诺。

训练菜单从 9 种餐品、15 种买法扩为 **20 种餐品、37 种买法、6 类、8 道预设题**。早餐堡、热香饼、薯饼、鸡块、鸡翅、鱼排堡、新地、奶昔、茶饮、橙汁、拿铁均可自由出题。首局仍只展示 6 种相关买法；「更多题目」和分类筛选逐步展开。所有训练金额都是虚构教学数据。

真实模式增加本店完整菜单及分类，可选择菜单条目开题，包含单品。开局重新获取菜单与默认选配，只有能准确对应商品编码、份数与默认特制的餐袋才进入核价。不支持的嵌套或特殊选配会明确拒绝；菜单显示不代表每项都保证可以开局。同一商品可能有多种规格，条目数不等于独立餐品数。实际供应由门店、时段与官方服务决定。

网页由单个 Worker 提供前端与模型转发，本机 Node 继续负责真实 MCP。线上不配置开发者的麦当劳 Token 或模型 API Key。应用没有账户体系、模型配置数据库或依赖第三方浏览器跨域策略。页面访问权限由部署者设置。

本机启动仍无需安装依赖：`node --env-file-if-exists=.env server.mjs`。仅构建线上包需要 `pnpm install --frozen-lockfile`，然后 `node scripts/build-worker.mjs`；固定 esbuild 版本与唯一安装脚本许可见项目配置。线上另需 secret `ARENA_TICKET_KEY`：32 字节随机值的 base64url 编码（43 字符），通过 Sites 环境变量设置，不写入源码。轮换会使旧票据失效。

验收结果在功能完成后记录到 `VERIFICATION_V03.md`；旧版记录保持历史日期，不作为当前价格承诺。
