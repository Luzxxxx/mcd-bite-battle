# 素材与参考说明

## 项目内容

前端、训练数据、套餐规则、Node 服务、官方接口适配、测试、文档和食品 SVG 示意图为本项目编写。SVG 使用基础几何绘制，不抓取官方商品图片或第三方作品。浏览器系统字体，无外部字体、图库和前端依赖。

训练场的商品组合、金额与优惠券是为玩法设计的虚构数据；真实模式的商品信息和价格来自持有 Token 后对官方 MCP 的查询。
