# v0.2：可邀请朋友的单人擂台

本轮范围：手机操作、同题分享、DeepSeek 工具出招、营业门店选择。遵照用户要求，先集中实现全部功能，再统一运行自动化、浏览器和真实服务联调。本轮验收已完成，结果记录在 [VERIFICATION_V02.md](VERIFICATION_V02.md)。

## 手机首局

底部固定餐袋数量、总价、对齐状态与出招按钮。点餐袋打开抽屉，复用同一份购物车状态与 DOM，调整份数、选券和看完整错误原因。锁定后收起浮动栏，把视线留给翻牌。

标准训练局默认六种相关买法，可以展开完整菜单。桌面保留右侧完整餐袋，键盘焦点、原生弹窗、减少动态效果设置继续可用。

## 同题链接

- 标准训练题：固定题目 ID 和数据版本。
- 自由训练题：只接受已知食品、每种最多两份、合计最多五份，以及合法预算。
- 完成后的训练题：可携带邀请者的方案与券，接收端重新检查餐袋并计算金额，翻牌后比较。链接不信任自报金额。
- 真实题：只带 caseId 与门店信息；接收者须使用自己的本机 MCP，重新搜索门店和核价。没有把历史报价包装成当下实付。

挑战内容在 URL fragment 中，不依赖账户、数据库或在线排行榜。链接有长度限制、版本校验、规范化与 HTML 转义；链接不提供防作弊排名。训练邀请使用策略对手，个人 DeepSeek 方案和密钥不随链接公开。分享不会改变站点的现有访问权限。

## DeepSeek

本机可在训练和真实模式邀请 DeepSeek。模型最多尝试三个报价方案，必须通过受限工具核价后原样提交，服务器提前保存答案。揭晓核对摘要与 nonce；真实模式重新核价。

模型失败时显示失败，不让训练局冒充真实报价，也不把策略算法冒充大模型。接口、参数与费用边界见 [MODEL_INTEGRATION.md](MODEL_INTEGRATION.md)。

## 门店与营业状态

用户输入城市和商圈关键词，官方返回门店。界面显示名称、地址、营业状态与营业时间，仅允许已确认营业的门店开启即时自取题目。未知状态不默认营业，不根据营业时间字符串推算当前是否可买。

每局保存所选门店上下文，玩家与对手都用该上下文报价；前端不能把一局中途换成另一家门店。菜单缺题、接口闭店或核价不完整时停止出题/判胜。暂不做预约、得来速和账户券。

## 本轮最终验收

统一检查：原有规则回归、分享往返与篡改拦截、模型工具限制与承诺、跨店上下文、手机抽屉和底栏、邀请者成绩比较、自定义分享、静态站点的接入提示，以及真实 DeepSeek 和官方服务可用性。

34 项自动化测试通过；五种视口宽度、抽屉和底栏、同题成绩比较均通过。真实 DeepSeek 在训练场完成工具出招，在官方门店对局中也通过了完整核价与同餐校验。结果分别保留证据，模拟响应测试不记作真实服务测试。

线上更新继续使用原站点、保持私有访问，提供策略训练、手机体验和同题链接。本机版提供 DeepSeek 与官方菜单核价。复制同题链接不改变访问权限，也不会让他人共用个人密钥。源码包排除 `.env`、原始响应和 Python 缓存。
