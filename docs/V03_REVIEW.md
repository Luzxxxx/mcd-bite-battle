# v0.3 简化与优化复盘

- 共用一个兼容工具调用对手，服务商差异集中在配置校验；本机默认 DeepSeek 是薄包装，避免为每家服务复制一套判胜逻辑。
- 网页、默认模型和自带模型使用同一份餐袋校验与训练计价。用版本化菜单保留旧分享链接，避免新餐品改变旧成绩。
- 线上用短期加密票据保留封存方案，无须保存玩家的 API Key 或搭建会话数据库。输入字段与对局、分享状态分开，结果卡使用真实对手名称。
- 先展示与当前题目有关的买法，更多题目、分类与完整门店菜单按需打开，避免扩充品类后把首屏堆满。
- 门店验证复用；额外随心配查询失败不影响已能核价的主餐开局。仍要求官方回执包含全部请求商品，避免「请求成功但漏算」产生假胜利。

仍可提升：支持更多官方复杂选配、为各服务商完善模型目录、为公开大规模访问增加持久限流。当前优先保持单人完整体验，未引入账号、排名或模型配置存储。网页真实核价仍需本机 MCP；未把开发者个人 Token 放到线上。
